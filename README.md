# MKorsakowsky-V2

## CV Project Description

**Personal Portfolio Website — Full Stack Developer**

Designed and developed a modern, fully responsive personal portfolio website to showcase professional experience, technical skills, and featured projects. Built with **Next.js 16** and **React 19** using **TypeScript** for end-to-end type safety, and styled with **SCSS** and **Tailwind CSS** following a mobile-first, responsive design approach.

Key highlights:
- Implemented smooth, performant animations and page transitions using **Framer Motion** and **GSAP**.
- Integrated interactive 3D graphics and visualisations with **Three.js** and **React Three Fiber / Drei**.
- Added an ambient particle system via **tsParticles** to enhance visual depth.
- Wired up a fully functional contact form backed by **EmailJS**, enabling direct email delivery without a dedicated backend.
- Structured content (experience timeline, project cards, skills) in reusable, data-driven React components to keep the codebase maintainable and easy to extend.
- Configured **ESLint** and enforced strict TypeScript settings for code quality.

**Tech Stack:** Next.js · React · TypeScript · SCSS · Tailwind CSS · Framer Motion · GSAP · Three.js · React Three Fiber · tsParticles · EmailJS
